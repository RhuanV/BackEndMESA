# Seed data — provenance & licensing

This folder holds committed seed data so a fresh clone shows the app working
without any external download (see [ADR 0007](../../docs/adr/0007-reproducible-deploy-demo-seed.md)).

| File | Content | Source / nature | License |
|------|---------|-----------------|---------|
| `state_boundaries.sql.gz` | Brazilian state boundaries | IBGE — BR_UF_2025 mesh | Open data (IBGE) |
| `demo_9999999_vetor.sql.gz` | Demo município + 5 vector layers (biomas, quilombolas, assentamentos, florestas públicas, geodiversidade) | **Synthetic demonstration fixture** generated by `make_demo_seed` | N/A (synthetic) |
| `demo_9999999_slope.tif` | Slope (percent) raster over the demo município | **Synthetic demonstration fixture** | N/A (synthetic) |
| `demo_9999999_landuse.tif` | MapBiomas-coded land-use raster over the demo município | **Synthetic demonstration fixture** | N/A (synthetic) |

## The demo município (`9999999`)

`9999999` is **not a real IBGE municipality**. It is a small synthetic polygon
placed over the interior of São Paulo state so Phases 4/5 are demonstrable
offline. Real data is ingested on the server via the Airflow DAGs
(`load_municipality_boundaries`, `load_incra_*`, `load_mma_*`, `load_cprm_*`,
`load_ibge_biomas`, `load_raster_anadem`, `load_raster_mapbiomas`).

## Regenerating the seed

```bash
python -m geoavia_backend.scripts.make_demo_seed        # vector + raster
python -m geoavia_backend.scripts.make_demo_seed vetor  # only vector
python -m geoavia_backend.scripts.make_demo_seed raster # only raster
```

The generator is deterministic (no randomness), so re-running produces identical
files. When real municipal data is desired instead of the synthetic fixture,
run the DAGs above (they read the real ANADEM/MapBiomas sources via GDAL
`/vsicurl` and clip per município — no multi-GB download).

## Real source references (used by the DAGs)

- **ANADEM** (MDT 30 m): UFRGS/IPH + ANA — MGRS tiles at
  `https://metadados.snirh.gov.br/files/anadem_v1_tiles/`.
- **MapBiomas** (uso/cobertura): Coleção Brasil, GeoTIFF anual em GCS
  (`storage.googleapis.com/mapbiomas-public/...`) — CC-BY-SA.
- **IBGE / INCRA / MMA / CPRM**: dados abertos das respectivas instituições.
